The gauntlet loop technique is Matt Shumer's, from
[Claude of Duty](https://github.com/mshumer/Claude-of-Duty).

This adaptation keeps the original Claude Code `/loop` + `ultracode` path
for Claude, and adds harness-specific run files so Codex, Copilot CLI,
OpenCode, and Grok Build use their own spawn and loop primitives instead
of those Claude commands.

A Grok-only fork also exists at
[aaronwJordan/gauntlet-loop-grok](https://github.com/aaronwJordan/gauntlet-loop-grok).
